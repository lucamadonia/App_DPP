# Trackbliss 1.2.0

Release candidate for the refreshed Trackbliss dashboard and hardened native delivery pipeline.

## Included

- Premium, responsive dashboard hero with live product, batch and document KPIs
- Optimized transparent dashboard artwork with explicit dimensions and high fetch priority
- Android App Link parity for authentication, customer portal, DPP, GS1 Digital Link and tenant routes
- Synchronized web, Android and iOS version metadata
- Release preflight gates for metadata, native invariants and unit tests
- Mandatory signing and store credentials for tagged mobile releases
- Signed IPA artifact retention and App Store package validation before TestFlight upload

## Store notes (DE)

Trackbliss 1.2.0 bringt ein neu gestaltetes Dashboard mit direktem Überblick über Produkte, Chargen, Dokumente und anstehende Compliance-Aufgaben. Verbesserte App Links öffnen Produktpässe und Kundenbereiche zuverlässiger direkt in der App. Zusätzlich wurden Stabilität und Release-Prüfungen für iOS und Android erweitert.

## Store notes (EN)

Trackbliss 1.2.0 introduces a redesigned dashboard with an immediate overview of products, batches, documents, and upcoming compliance actions. Improved App Links open product passports and customer areas more reliably in the app. Stability and release checks for iOS and Android have also been strengthened.

## Automated release gates

- `npm run check:release`
- `npm run check:native`
- Unit tests, lint, production build and Playwright E2E suite
- Android native compile with API level 36
- iOS unsigned compile on macOS; signed archive validation in the tagged workflow

## External store gates

The release tag is intentionally created only after the App Store Connect and Google Play credentials are confirmed in GitHub Actions. After Play App Signing is enabled, its app-signing SHA-256 certificate fingerprint must also be published in `assetlinks.json`.
